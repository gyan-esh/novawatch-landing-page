# NovaWatch - Responsive Product Landing Page

## About the Project

NovaWatch is a responsive product landing page created as part of
the Week 02 Web Development Minor Project.

The project demonstrates modern web design concepts including
CSS3, Flexbox, CSS Grid, responsive design and Tailwind CSS.

## Product

NovaWatch Pro is a fictional smartwatch designed for health,
fitness and everyday smart features.

## Features

- Health tracking
- Fitness tracking
- Smart notifications
- Long battery life
- Responsive design

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Tailwind CSS
- Git
- GitHub
